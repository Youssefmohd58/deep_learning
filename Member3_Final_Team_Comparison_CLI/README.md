# CUB-200: Member 3 evaluation & final three-model integration (VS Code / CLI)

This project combines **Member 3's pretrained ResNet-18 and EfficientNet-B0 evaluation code** with **Member 2's final pretrained-free five-block CNN checkpoint**. It uses the public CUB-200-2011 official test split (5,794 images) and the team's exact saved training/validation manifest. No Jupyter notebook is required. Modules remain separate as required by project Sections 5.2–5.4.

## Important: what has and has not been measured

- The supplied `team_assets/member2/best_model.pth` is Member 2's **epoch 78** scratch CNN checkpoint with **60.05% validation accuracy** in its metadata. **This is not test accuracy**.
- Member 3's earlier **67.60% ResNet-18** and **76.34% EfficientNet-B0** test accuracies were from earlier Colab executions. They are **not preloaded** or regenerated by this source archive. To evaluate or compare all three, copy your original compatible trained pretrained `.pt` checkpoints or train the models with this CLI.
- The checkpoint has a 200-class `BirdCNN` and is verified to load strictly. The full 5,794-image official test evaluation is **not run inside this archive**; run the evaluation command below.
- Member 2's model takes **128 × 128**, whereas ResNet-18 / EfficientNet-B0 take **224 × 224**. The test **photos** and labels are identical, but the pixel-level preprocessing is intentionally model-specific and must be documented as a comparison limitation.
- Member 1's duplicate-image audit should be confirmed complete before declaring final results.

## Set up in VS Code (Windows PowerShell)

1. Extract the ZIP, open this folder in VS Code (the folder containing `src/`).
2. Install Python 3.11 64-bit, then in **Terminal → New Terminal**:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.cli check
```

If PyTorch doesn't detect a CUDA GPU, install its CUDA-enabled wheel pair following the official PyTorch install instructions. Use `uv venv --python 3.11 .venv` if `py -3.11` is unavailable. **Run all commands from the project root.**

## Step 1: evaluate Member 2's latest checkpoint (no scratch retraining)

```powershell
.\.venv\Scripts\python.exe -m src.cli evaluate --model scratch_cnn --config configs/classification.yaml
```

This downloads the official Hugging Face dataset as necessary, loads the best 5-block checkpoint at 128px, and exports `outputs/member3/predictions/scratch_cnn_test_predictions.csv`, JSON metrics, class metrics, and 200 × 200 confusion matrix. It does **not** run hyperparameter tuning or train the scratch model again.

## Step 2: evaluate the Member 3 pretrained checkpoints

If you still have your previously trained pretrained checkpoints, place them here:

```text
outputs/member3/checkpoints/resnet18_best.pt
outputs/member3/checkpoints/efficientnet_b0_best.pt
```

They must be compatible state-dict checkpoints with `architecture`, `class_names`, and `model_state_dict` (the project's previous training code uses this schema). The evaluation validates class order and, if present, split hash. Alternatively train the models from scratch using pretrained ImageNet weights: 

```powershell
.\.venv\Scripts\python.exe -m src.cli train --model all --tune --config configs/classification.yaml
```

Then evaluate:

```powershell
.\.venv\Scripts\python.exe -m src.cli evaluate --model resnet18 --config configs/classification.yaml
.\.venv\Scripts\python.exe -m src.cli evaluate --model efficientnet_b0 --config configs/classification.yaml
```

For the full 3-model evaluation in a single command (after both pretrained checkpoints exist):

```powershell
.\.venv\Scripts\python.exe -m src.cli evaluate --model all --config configs/classification.yaml
```

## Step 3: compare all THREE models

```powershell
.\.venv\Scripts\python.exe -m src.cli compare --config configs/classification.yaml
```

This checks that the **same 5,794 official test rows**, labels, and filenames are present in each CSV. It writes `outputs/member3/metrics/three_model_comparison.csv` and `outputs/member3/figures/three_model_comparison.png`.

You can also compare just two models, e.g. `compare --models resnet18 scratch_cnn`.

## Inference and Grad-CAM for any of the three models

```powershell
.\.venv\Scripts\python.exe -m src.cli predict --checkpoint team_assets/member2/best_model.pth --image "path/to/bird.jpg" --top-k 5
.\.venv\Scripts\python.exe -m src.cli gradcam --checkpoint team_assets/member2/best_model.pth --image "path/to/bird.jpg" --output outputs/member3/figures/scratch_example.png
```

Substitute a `resnet18_best.pt` or `efficientnet_b0_best.pt` checkpoint to use your transfer models. For all new training, validation selection comes **before** test evaluation. Do not tune models based on test outcomes.

## One-command full pipeline

```powershell
.\.venv\Scripts\python.exe -m src.cli pipeline --config configs/classification.yaml --model all --tune
```

Runs tuning, head and fine-tuning for both Member 3 models, evaluates the pretrained and supplied scratch checkpoint, generates Grad-CAM for the pretrained models, and creates the 3-way comparison. It does **not** retrain Member 2's CNN. The original shorter 3+3 pretrained training schedule is preserved.

## Notes on fairness, reproducibility and final submission

`configs/train_validation_split.csv` matches the previous team split byte-for-byte. The program will **not** overwrite it. All pretrained models use the same official CUB class IDs 0–199, and the scratch checkpoint was saved for 200 outputs. Test accuracy, macro precision, macro recall, macro F1 and confusion matrices are all calculated using the same functions.

The final combined course submission must also merge Member 1's data/EDA modules, colorization and captioning tasks in Milestone 2, team GitHub history, and a team-level CLI as applicable. This project specifically covers **Milestone 1, Member 3 evaluation and integration with Member 2's scratch model**.
